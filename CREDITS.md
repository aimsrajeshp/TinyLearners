# Third-party assets

- **Fonts:** Baloo 2 and Nunito, from Google Fonts, licensed under the SIL Open Font License.
- **Tracing letter/number paths** (`data/trace_paths.json`): stroke coordinates derived from the
  Hershey "Simplex" vector font, via the MIT-licensed JSON port at
  https://github.com/techninja/hersheytextjs (Copyright (c) 2014 James T). The Hershey fonts
  themselves are public domain (created by Dr. A. V. Hershey, U.S. National Bureau of Standards).
- **Placeholder voice lines** (`audio/voice/`): synthesized with the Windows built-in
  text-to-speech engine (SAPI, "Microsoft Zira Desktop"). Intended as a stand-in for real
  recorded narration before release - see Tiny-Learners.md Phase 7.
- **Placeholder sound effects** (`audio/sfx/`): simple synthesized tones generated for this
  project, not third-party assets.
- **Logo:** provided by the project owner (`document/logo.png`).
